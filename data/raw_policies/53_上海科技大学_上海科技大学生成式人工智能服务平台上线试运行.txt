日期：2024-04-12
文章来源：图书信息中心
为进一步推进人工智能在教学、科研和管理中的应用，图书信息中心上线试运行
生成式人工智能服务平台
（以下简称“平台”，网址：
https://ai.shanghaitech.edu.cn
），旨在为全校师生提供高效便捷的工具和技术支持。
平台包括文本对话
GenAI Web Chat
、
GenAI API
等多种服务，及推荐的教学、科研、写作、办公
AI
工具等。同时，图书信息中心根据国家法律法规要求，制定了《
上海科技大学生成式人工智能使用指南
》，倡导用户合法合规、负责任地使用生成式人工智能服务和工具。
GenAI Web Chat
服务
(
内网访问
平台
，点击“
GenAI Web”
进入，学校统一认证账号登录
)
采用微软海外云
Azure
提供的
OpenAI
服务，网络传输使用公网。暂提供文生文（
GPT-3.5 Turbo
、
GPT-4
、
GPT-4 Turbo
）服务，文生图（
Dall-E 3
）服务。虚拟配额
资源
，
促进
合理使用。
GenAI API
服务
集中提供对
GPT
、
LLama2
、
ChatGLM3
、
M3E-base
等模型接口的便捷访问，并配备
Stable Diffusion
模型的云桌面运行环境。因资源有限，该服务采用教师
申请
，学校综合评估审核后向申请者开放使用。
人工智能工具汇总
提供通用及分领域人工智能工具、编程工具、文献工具的访问链接及使用介绍。在
教学场景应用
如教师有兴趣应用人工智能辅助构建学科领域知识库和尝试使用专用智能问答，图信中心愿与您共同
探索
，协助技术支持。
为了帮助大家更好地了解和应用生成式人工智能技术，图信中心将推出“
AI
素养”系列讲座。敬请关注平台的“培训讲座”模块或关注图书馆邮件通知。详细内容请参见平台网站。温馨提醒：学校师生使用生成式人工智能技术及工具时，应遵循《
上海科技大学生成式人工智能使用指南
》的指导性原则和规范。
